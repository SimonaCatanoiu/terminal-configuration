# Terminal Configuration

A central repository for my personal terminal configuration settings for Linux and macOS shells.

### Features:
- Configurations for **Bash** and **Zsh** shells.
- Easy setup with a script to apply the configurations.

### Setup:
1. Clone this repository.
2. Run the setup script to apply the configurations.

```bash
git clone https://github.com/SimonaCatanoiu/terminal-configuration
cd terminal-configuration/(bash|zsh)
./terminal_config.sh
```
